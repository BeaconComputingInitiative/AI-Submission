## M4.3 user-side evaluation details

128 held-out synthetic cases in domains 10 and 11; calibration on domains
8 and 9, separately from training domains 0–3. L10 contextual matching
accuracy **0.9140625**, L11 original-unit forecast MAE **5.214981697772217**,
persistence MAE **23.28187362523662**, linear extrapolation MAE
**6.858620105462808**. All configured evidence controls passed. The 90%
nominal forecast interval obtained **0.9375** observed coverage in that split,
with mean interval width **29.97227311759523** original units.

This is a **synthetic model-specific benchmark**, not verified forecasting
performance in businesses or external markets. Independent domains do not
necessarily satisfy conformal exchangeability assumptions.

## M4.4 public-data test and recovery

Public-data bridge compares BLS unemployment rate series **CAUR** and **NVUR**
via the Federal Reserve Bank of St. Louis FRED as an *exercise*, not as a
business-sales claim. The M4.4 code and combined test suite passed locally,
but the user's first FRED download failed with `The read operation timed out`.
Thus no M4.4 real-data training result is claimed here.

Use `scripts/recover-a440-m44-data.sh` on Kali to retrieve those CSV files
with retries, validate rows and provenance, and check SHA-256. Then run the
existing M4.4 real-world experiment. The script refuses to overwrite an
existing destination. Third-party source data and local trained checkpoints
are intentionally excluded from this repository.
