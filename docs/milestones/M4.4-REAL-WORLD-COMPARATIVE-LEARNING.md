## Objective

Test whether historical **broader-context observations** help A440 predict
an observed local numerical outcome, rather than assuming external data helps.

The reference public experiment uses **California unemployment rate (CAUR)**
and **Nevada unemployment rate (NVUR)**, seasonally adjusted percentages,
monthly, supplied by the U.S. Bureau of Labor Statistics via FRED.

- Local context: CAUR
- Broader context: NVUR
- Target: CAUR at the next month (one-step forecast)
- Historical input: eight consecutive aligned months per source
- Comparison: a local-only A440 M4.1 encoder/forecast vs. a gated
  market-context model initialized from the same M4.1 checkpoint.
- Statistical baselines: persistence and two-point linear extrapolation.

Official sources:
- https://fred.stlouisfed.org/series/CAUR
- https://fred.stlouisfed.org/series/NVUR
- https://fred.stlouisfed.org/help/data/downloading/using-the-download-data-link/

These are *regional labor-market indicators*, NOT sales, company revenue,
or causal evidence about a business. Their use demonstrates an engineering
capability, not a claim about another organization's records.

## Install and run

The package has these relative paths:

```text
src/bcipitch/realworld_bridge.py
tests/test_realworld_bridge.py
docs/milestones/M4.4-REAL-WORLD-COMPARATIVE-LEARNING.md
SHA256SUMS
```

After verified installation in the BCIPitch repo, run:

```bash
python3 src/bcipitch/realworld_bridge.py fetch \
  --outdir "$HOME/Documents/A440-M4.4-CA-NV-1990-2025"

python3 src/bcipitch/realworld_bridge.py run \
  --data-dir "$HOME/Documents/A440-M4.4-CA-NV-1990-2025" \
  --checkpoint experiments/A440-M4.1-run-xUYNdA/learned_truth_candidate.pt \
  --outdir experiments/A440-M4.4-run-001
```

**Each output directory must not already exist.** The tool does not overwrite.
The command above needs network access to fetch the two public CSV files. If
FRED blocks the request or network is unavailable, the command reports failure;
it does not substitute fabricated values. FRED's graph export is convenient
but may change; CSV downloads are documented through the graph interface.

## Evidence contract

`sources.json` records the exact CSV bytes' SHA-256 hashes, series names,
source URLs, units, frequency, adjustment method, and retrieval timestamp.
Data rows must have unique chronological first-of-month dates and finite
numbers. Missing values are not fabricated. Windows spanning a missing month
are excluded. Source and checkpoint hashes must pass verification **if and
only if** they match the bytes actually read.

Matched sources must use the *same* declared unit, reporting frequency and
seasonal adjustment. These conditions alone do not prove causal or substantive
comparability; an analyst must validate population, methodology and purpose.

## Evaluation contract

- Chronological targets: 60% training, 15% model selection, 10% interval
  calibration, remaining 15% final test.
- The ninth (target) monthly value is never passed into the encoder.
- Both networks initialize from the verified M4.1 weights, but **fine-tuning
  occurs only in M4.4 candidate files**. Existing A440 checkpoint remains
  unchanged.
- Reports include local-only and market-context test MAE, persistence MAE,
  extrapolation MAE, test dates, source SHA-256 hashes and candidate weights.
- Additional context **earns** a positive result only if the contextual model's
  held-out error is lower than the local-only model's error. This is a diagnostic
  comparison, not proof of a causal effect of market knowledge.
- A separate calibration block estimates a 90% residual interval. Because
  chronological time-series shifts violate some exchangeability assumptions,
  the reported empirical coverage has **no formal distribution-free guarantee**.
- Trained model promotion and deployment approval remain **disabled**.

## Evaluation caveats and next work

- FRED historical observations may be revised later. Source SHA and fetch
  timestamp make one download reproducible, but this is **not a real-time,
  vintage-correct backtest**. For vintage-correct testing, use ALFRED or other
  point-in-time datasets with actual historic publication dates.
- Both sets of rolling windows overlap within each split; chronological split
  prevents the model from training on later targets, but dependence persists.
- There is no independent evidence of causality from correlated rates.
- The market-context model has slightly more parameters (gating coefficients).
- This milestone specifically validates the L10/L11 comparative/forecasting
  bridge. It does not revalidate L09/L12 or finish the Chorded Truth integration
  for real, externally verified business claims.
- For future private business records, use explicit consent, tenant-bound
  ingestion and private storage **outside a public Git repository**.
